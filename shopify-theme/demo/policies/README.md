# Policy Shopify (Settings → Policies)

Incolla ogni file nel campo corrispondente. Poi crea 5 Pagine (Online Store → Pages) con handle:

- `privacy` → template **page.privacy**
- `cookies` → **page.cookies**
- `terms` → **page.terms**
- `refund` → **page.refund**
- `shipping` → **page.shipping**

Compila Tema → Legal: P.IVA, REA, PEC, email.
